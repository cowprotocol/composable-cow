# Canonical initcode

The exact initcode of the official deployments, one file per contract, plus a `manifest.json`
recording the salt and resulting address of each.

These bytes are not generated by compiling this repository. Because of
[#93](https://github.com/cowprotocol/composable-cow/issues/93) a fresh build produces the same
runtime code but a different Solidity metadata hash, and since that hash is part of the `CREATE2`
preimage the resulting address differs. The initcode here was read back from the deployment
transactions of the existing contracts, so it is the only thing that still reproduces the addresses
in `networks.json`.

Deploy it to a new chain with [`dev/deploy-canonical.sh`](../dev/deploy-canonical.sh).

## Do not edit

Every file is verified against `manifest.json` before deployment: `CREATE2` over the recorded
initcode and salt has to equal the recorded address. Editing any of it makes the check fail, which
is the point — a change here would otherwise deploy different code to a trusted address.

Note the salts are not uniform. `ComposableCoW`, `CurrentBlockTimestampFactory`,
`ExtensibleFallbackHandler`, `PerpetualStableSwap` and `TWAP` were deployed with `v1.0.0`, while
`GoodAfterTime`, `StopLoss` and `TradeAboveThreshold` were deployed with a zero salt.
